# IPL TABLEAU DASHBOARD🏏🏆
I have created 2 IPL Dashboards using Tableau.
The First one shows the Matches won based on Toss Decision and Toss Decision Based Winnning % along with Title Winner 🏆, Orange cap holder, Purple Cap holder, Tournament 6️⃣ and Tournament 4️⃣ season wise 📅.
And the second one shows Batting and Bowling Stats. 📈📉

## CSV Files Used:
- IPL Ball-by-Ball 2008-2020.csv
- IPL Matches 2008-2020.csv

# Features

- View Interactive Dashboards built using Tableau.
- Change the season from dropdown and the stats will change accordingly.
- There are 2 Dashboards showing Title Winner, Orange-purple cap holder, Tournament 6️'s and 4️'s, Batting and Bowling Stats.
